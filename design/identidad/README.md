# Identidad gráfica de Tinta

[Abre la lámina comparativa](logos/comparativa.html) para ver las cuatro firmas. En «¿Cuánto color?» puedes pasar a las tres muestras de Ajustes. La lámina lleva sus imágenes y tipografía dentro del propio HTML. Puedes compartirla por separado para revisar los signos y el ícono. Para abrir también las muestras de Ajustes, usa el paquete completo.

**Punto de partida.** La gota y el nombre Tinta identifican al equipo. El favicon y la app instalada llevan «tc» sobre azul petróleo. Conservamos Manrope, el menú y los colores de estado. Proponemos unificar la firma del CRM y dar más presencia al color dentro de las pantallas.
